Detect the Dataframe Conversion API Misused (DCA) code smell in the provided Python source code.

TASK

Identify every occurrence where the Pandas .values attribute is used to obtain the underlying NumPy array representation of a Pandas DataFrame or Series, instead of using the explicit .to_numpy() API.

Detect only this code smell. Do not report unrelated defects, code complexity, incorrect return values, exception handling issues, or general programming problems.

SMELL DEFINITION

Pandas DataFrame and Series objects expose a .values attribute that returns their underlying array representation.

For explicit NumPy conversion, the preferred API is .to_numpy().

Examples of violations:

    X = df.values
    y = df["target"].values
    X = df[feature_columns].values
    X = df.drop(columns=["target"]).values
    X = df.iloc[batch_indices, :].values
    y = df.iloc[batch_indices]["target"].values
    X = pd.concat(frames, axis=1).values
    model.fit(df.values, labels)
    return dataframe.values

Preferred alternatives:

    X = df.to_numpy()
    y = df["target"].to_numpy()
    X = df[feature_columns].to_numpy()
    X = df.drop(columns=["target"]).to_numpy()

DETECTION CRITERIA

Report a violation only when all the following conditions hold:

1. The source contains an actual access to an attribute named .values.
2. The receiver is a Pandas DataFrame or Pandas Series, as established from the available source code.
3. The attribute is used to obtain the object's underlying array representation.

The .values attribute may appear in assignments, function arguments, return expressions, chained expressions, indexing operations, or NumPy and PyTorch conversions.

The conversion does not need to be assigned to a variable.

Both are eligible when their .values attribute is accessed for array conversion.

EXCLUSIONS

Do not report:

- dictionary.values() calls.
- User-defined values() methods.
- .values attributes of objects that are not Pandas DataFrames or Series.
- Enum .value accesses.
- Other conversion methods, such as .to_numpy(), np.array(...), or np.asarray(...), when no qualifying Pandas .values access occurs.
- Statements that merely create, manipulate, filter, or concatenate DataFrames without accessing .values.
- General performance, maintainability, or correctness issues unrelated to this smell.
- Hypothetical conversions or operations inferred from the purpose of a function.
- Comments, documentation, or string literals containing .values.

The presence of the word "values" alone does not establish a violation.

In particular, a dictionary.values() call must never be classified as a Pandas conversion.

Do not report an occurrence when the available code establishes that the receiver is not a Pandas DataFrame or Series.

If the receiver's Pandas identity cannot be established with reasonable confidence, exclude the candidate rather than inventing a type relationship.
